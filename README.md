# 復古 Win95 小遊戲 · win95-simulator-game

一個復古 Windows 95 風格的桌面小遊戲合集，帶你重溫「史萊姆的第一個家」世代的童年神作。

🎮 **線上遊玩 / Play online：** https://xinyujian.github.io/win95-simulator-game/

## 內容 / Features

- **翻翻樂（記憶配對）** — 分兩隊翻牌配對、大聲喊出名稱得分；內建 10 秒倒數加壓與「說出名字」判分機制。
- **圈圈叉叉（○ ✕ 連線）** — 每格是一款復古小遊戲，先連成一線者勝。
- **桌面寵物 Vicky** — 會在桌面散步、討食、鬧脾氣的小彩蛋。

單頁 HTML，響應式設計，一個畫面塞得下，適合投影同樂。
